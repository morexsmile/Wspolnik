# Team & Project Management Dashboard

A modern and responsive team management dashboard designed to help teams organize projects, track tasks, and collaborate in one place.

## Features

- **Dashboard** — Overview of projects, tasks, and team activity.
- **Project Management** — Browse and monitor project progress.
- **Task Management** — Add tasks, set priorities and deadlines, and track completion.
- **Team Management** — Add and manage team members.
- **Calendar** — Dedicated calendar view for upcoming deadlines.
- **Search** — Quickly find tasks and projects.
- **Responsive Layout** — Interface adapted for desktop and mobile devices.
- **Local Storage** — Save tasks and their statuses in the browser.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts 
- LocalStorage API





The project is a front-end prototype. Data is stored locally in the browser using LocalStorage and is not synchronized between different users or devices.
